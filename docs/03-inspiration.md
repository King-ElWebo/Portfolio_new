# Visual & Interactive Inspiration

> **Zweck**: Strukturierte Sammlung von Referenz-Websites, Interaktionsmustern und gestalterischen Vorbildern.  
> **Source of Truth**: Inspiration & Benchmark-Analyse

---

## 📋 Standardisiertes Referenz-Schema

Jede neue Inspiration soll nach folgendem Format dokumentiert werden:

```text
REFERENCE: [Name / Titel der Website]
URL: [https://...]
TYPE: [Portfolio | Studio | Brand | Editorial | Interaction Showcase]
WHAT I LIKE: [Konkrete Aspekte, Typo, Motion, Farbkombination, Rhythmus]
WHAT I DON'T LIKE: [Was vermieden werden soll, z. B. zu langsam, unleserlich, unruhig]
USE FOR: [Konkreter Einsatzbereich, z. B. Hero-Übergang, Case-Study-Grid, Typo-Skalierung]
NOTES: [Zusätzliche Beobachtungen oder technische Besonderheiten]
```

## 📝 Checkliste zur Bewertung von Referenzen
- [ ] Unterstützt die Referenz das Ziel: **Vertrauen aufbauen**?
- [ ] Wirkt die Seite zeitlos oder verfällt sie kurzlebigen Trends (Bento-Grids, unleserliche Micro-Fonts)?
- [ ] Lässt sich die Interaktion performant und barrierearm umsetzen?
- [ ] Funktioniert die Typografie auf mobilen Endgeräten ebenso stark wie auf großen Bildschirmen?
