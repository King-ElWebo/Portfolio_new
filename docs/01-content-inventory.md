| :--- | :--- |

| `WORKING DIRECTION` | Aktuell bevorzugte Richtung; wird noch erprobt oder verfeinert. |
| `NEEDS CONFIRMATION` | Plausibler Vorschlag oder Annahme; muss vom Nutzer bestätigt werden. |
